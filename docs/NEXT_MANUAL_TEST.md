# Проверка 2.0.0-alpha.1 на Forever

Это план ручной проверки. Ни один пункт не помечен пройденным без игрового клиента.

1. Зафиксировать build, язык, UI scale, версии сумок; начать с отключённым Questie. Включить core и Guide, выполнить `/qiq status` и `/qiq`.
2. Alt+ЛКМ: активное задание открывается; при нескольких — меню. Shift+ЛКМ вставляет ссылку/выполняет штатное действие. Ctrl+ЛКМ сохраняет примерку. Чат в фокусе, ПКМ и неизвестные кнопки не перехватываются.
3. Ctrl+Alt+ЛКМ: справочник фильтруется по предмету. Проверить 5827 и 9173, если доступны; `/qiq item ID` — запасной вход, но не замена проверки клика.
4. `/qiq key altshift`, затем `alt`, затем `off`: точные сочетания и подсказки соответствуют настройке. После reload настройка сохраняется.
5. Поиск «Мартек», «Martek», 1106, NPC, предмета и зоны; фильтры «Все / Активные / Завершённые / Нет в журнале»; очистка фильтра предмета, страницы, цепочки, назад/вперёд.
6. Проверить цель, начало/сдачу и места на 10 известных квестах, включая новый Forever-квест, повторяемый, доставку и разветвление. Пропуски базы и расхождения записать с ID, а не исправлять по догадке.
7. Координата на карте: валидная native-точка, неподдерживаемая карта, TomTom включён/отключён. Не должно быть точки 0,0 из неизвестной координаты. Сверить геометрию нескольких разнесённых ориентиров.
8. Принять/обновить/бросить/сдать задание при открытой карточке; прокрутка сохраняется. Поздний item cache не сбрасывает выбранный квест.
9. ruRU/enUS × стандартные сумки/Bagnon. Длинные названия, края экрана, малое разрешение, reload, бой. Записать Lua errors и taint; отсутствие ошибок в mock не закрывает этот пункт.
10. Сравнить потребление памяти до и после первого открытия Guide; после 100 повторных открытий/поисков не должно быть неограниченного роста. Зафиксировать размер интерфейса и читаемость масштабирования.

Для каждого пункта: конфигурация → входные ID → действие → фактический результат → пройдено/не пройдено/не выполнено. Критические проблемы: неверный квест, потерянный штатный клик, Lua error, вмешательство в чужой tooltip, неверная карта.
