# Ручная проверка в WoW Forever 1.60.1

Перед проверкой сделайте резервную копию установленного аддона, скопируйте папку `QuestItemQuests` в `Interface/AddOns`, включите Lua errors и выполните `/reload`.

- [ ] `/qiq status` показывает версию 1.4.1 и не вызывает Lua-ошибок.
- [ ] Для предмета одного активного задания companion-подсказка показывает зелёное название и Shift+ЛКМ открывает правильное задание.
- [ ] Для предмета двух активных заданий появляется меню; каждая кнопка открывает выбранное задание.
- [ ] Если открытие пункта меню возвращает ошибку, меню остаётся открытым, появляется краткое сообщение и можно выбрать задание повторно.
- [ ] Для известного предмета без задания показаны жёлтый статус и красные названия, Shift+ЛКМ выполняет стандартное действие.
- [ ] Для предмета, являющегося только наградой, активный квест не предлагается; обычная награда не класса 12 не помечается.
- [ ] Для неизвестного предмета класса «Задание» показано «связанное задание не определено».
- [ ] При принятии, сдаче и удалении задания уже открытая companion-подсказка обновляется без повторных строк.
- [ ] Предмет с ещё не загруженным `GetItemInfo` получает корректный блок после загрузки данных.
- [ ] Проверить dynamic-only предмет без статической связи и classID: после загрузки имени должен появиться активный квест.
- [ ] Строки Mastercraft, Questie, Auctionator и других аддонов в основной подсказке сохраняются.
- [ ] GameTooltip, ItemRefTooltip, сравнение ShoppingTooltip и WorldMapTooltip не вызывают Lua-ошибок.
- [ ] Shift+ПКМ, Shift+средняя кнопка, обычный ЛКМ и клики по ссылке в чате сохраняют стандартное поведение.
- [ ] При активной строке ввода чата Shift+ЛКМ не открывает квест и вставляет ссылку стандартным способом.
- [ ] Проверить стандартные сумки и используемый Bagnon/BagBrother; кнопка должна иметь подтверждённые bag/slot.
- [ ] Временно отключить API карты или воспроизвести ошибку: стандартный обработчик должен получить клик.
- [ ] Проверить масштаб UI 64%, 100% и максимальный: companion-подсказка не должна выходить за экран или закрывать важные элементы.
- [ ] `/qiq debug 5827` и `/qiq test 5827` выдают диагностику без ошибок.
