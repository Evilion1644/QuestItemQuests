# Quest Item Quests

Небольшой аддон для WoW Forever 1.60.1 (Interface 16001). В подсказке предмета он показывает активные квесты, для которых предмет является целью, а для квестового предмета без активного задания сообщает это и выводит названия связанных квестов. Shift+ЛКМ по предмету в настоящей кнопке сумки открывает только активный квест; если квестов несколько, появляется меню выбора.

В версии 1.4.1 названия активных квестов выделяются ярким мятно-зелёным цветом, а известные связанные квесты без активного задания — светло-красным. Для известной связи без активного задания выводится короткая жёлтая строка «активного задания нет».

Установка: скопируйте папку `QuestItemQuests` в `Interface/AddOns` и включите аддон в списке персонажа. Аддон рассчитан на WoW Forever 1.60.1 (клиент 1.60.1.70291).

В архив включён компактный числовой индекс Forever DB (`QuestItemQuestsData.lua`). Он строится из objectives (поле 10, группа item), sourceItemId (11), requiredSourceItems (21), startedBy item (группа 3), itemDB startQuest (5), relatedQuests (15) и questRewards (6). В индекс также включён компактный словарь названий только для связанных квестов: сначала используется перевод ruRU, затем английское название из базы; ID показывается лишь как крайний fallback. Награда хранится отдельным типом связи и сама по себе не открывается кликом без активного квеста. Например, Goblin Transponder (9173) связан с квестом «Поехалиии!» (2843) как награда.

Для определения типа предмета сначала используется `C_Item.GetItemInfoInstant`, а затем встроенный fallback по `itemDB` (classID 12). Поэтому Goblin Transponder корректно помечается и на клиенте, где этот API отсутствует или возвращает другую форму. Обычная награда без classID 12 не помечается автоматически.

Для заданий доставки, где API показывает только обычный текст цели (например, «Отнесите письмо Пшикса Мартеку Изгою»), сохраняется узкая эвристика: первые два слова названия предмета должны встретиться в цели, а цель должна содержать глагол доставки. Сопоставление чувствительно к активному журналу заданий и локализации.

Обёртка клика срабатывает только при Shift+ЛКМ, когда фокус — кнопка предмета с подтверждёнными bag/slot и совпадающей ссылкой; ПКМ, средняя кнопка, неизвестная кнопка и отсутствующий API определения кнопки передаются исходной функции. Это намеренно fail-closed: BagBrother-вызов `HandleModifiedItemClick(link)` без button не открывает квест, если клиент не предоставляет `GetMouseButtonClicked`. При отсутствии API открытия журнала или несовпадении текста исходное действие сохраняется. Для диагностики доступны `/qiq status` и `/qiq debug`; `/qiq debug 5827` принимает ID, `item:5827` или вставленную полную ссылку предмета.

Предусмотрена совместимость с Blizzard bags и Bagnon/BagBrother: используются `GetBag`/`GetBagID`, поля `bag/bagID`, `GetID()` и родительская кнопка. Индекс получен из QuestieDB Forever commit `e0a6eaa86f181ac99262e34126bcd2ed1a1712d6`; исходная база в архив не копируется. Игровой клиент отдельно не запускался.
