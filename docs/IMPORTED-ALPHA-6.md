# Восстановленная локальная версия 2.0.0-alpha.6

Исходники восстановлены из `quest-item-quests-roadmap/work/QuestItemQuests-next`, задачи «Развитие QuestItemQuests», 11 октября 2026 года. Перед переносом проверены SHA-256 всех 14 файлов установленной сборки: они совпали с исходниками и `BUILD-MANIFEST.json` локальной сборки alpha.6. Папка установки: WoW `_classic_beta_/Interface/AddOns`.

Оба исходных модуля перенесены, затем по выбору владельца переименованы в `QLens` и загружаемый по требованию `QLens_Guide`. Изменены названия в TOC/UI, путь загрузки Guide и добавлен псевдоним `/qlens`; старый `/qiq` сохранён. Базы данных не изменены. С модулями сохранены исходные тесты, генераторы данных, контрольные списки и сведения об источниках/лицензиях. Аудит описывает этапы локальной разработки и может содержать более ранние номера alpha; текущую версию определяют TOC обоих модулей.

Эта версия включает справочник по 4244 заданиям, локализацию ruRU/enUS, Classic-справку по наградам, исправление пустых ответов клиента и отображение полного списка наград в карточке задания. Сочетания клавиш из установленной версии: Alt+ЛКМ — активное задание, Ctrl+Alt+ЛКМ — справочник; `/qiq` — открытие справочника. Это восстановленные изменения предыдущей разработки, а не новые изменения игровой логики при переносе.

Данные Classic явно являются справочными и не подтверждают награды Forever. Описание происхождения данных сохранено в `THIRD_PARTY_NOTICES.md`; историческая оговорка о неустановленных условиях распространения QuestieDB не является утверждением о новой лицензии аддона.

Автоматизация теперь проверяет оба модуля и поддерживает `vX.Y.Z-alpha.N` / `vX.Y.Z-beta.N` наряду со стабильными тегами. Тип файла CurseForge соответствует суффиксу. Перенос в `main` запускает только тесты и сборку; релизный тег при переносе не создаётся.
