# Переход с QuestItemQuests на QLens

QLens — новое имя того же аддона. Репозиторий `Evilion1644/QuestItemQuests` и CurseForge Project ID `1734956` сохраняются, чтобы не создавать второй проект и не терять историю релизов.

Новый ZIP устанавливает две папки рядом в `Interface/AddOns`: `QLens` и `QLens_Guide`. Вторая загружается по требованию. Не держите включёнными старые `QuestItemQuests` / `QuestItemQuests_Guide` одновременно с QLens: обе версии обрабатывают подсказки и клики.

Чтобы перенести локальную установку:

1. Полностью закройте WoW и сохраните резервную копию двух старых папок вне `Interface/AddOns`.
2. Уберите старые папки из `Interface/AddOns`, затем распакуйте `QLens` и `QLens_Guide` из нового ZIP.
3. Если нужно сохранить выбранное сочетание клавиш, скопируйте файл `WTF/Account/<учётная запись>/SavedVariables/QuestItemQuests.lua` в той же папке как `QLens.lua`. Переменная внутри остаётся `QuestItemQuestsDB`; редактировать содержимое не нужно. Не перезаписывайте существующий `QLens.lua` без резервной копии. Без этого шага используются стандартные настройки Alt+ЛКМ.
4. Запустите игру, включите QLens и QLens — Guide. Откройте справочник командой `/qlens`. Старая команда `/qiq` также сохранена.

Alt+ЛКМ открывает активное задание, Ctrl+Alt+ЛКМ — справочник по предмету. Смена имени не меняет базу предметов, заданий и наград.

Эта инструкция описывает установку после выпуска ZIP. При переносе исходников на GitHub установленная папка игры и пользовательские SavedVariables не изменяются.
